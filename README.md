# بيتي POS — نظام إدارة محلات المواد والأجهزة المنزلية

نظام متكامل لإدارة محل بيع مواد وأجهزة منزلية: **بيع نقدي وبيع بالأقساط**، إدارة الزبائن والمنتجات والمخزون والأرباح
والتسديدات والضمان والصيانة والتوصيل والموردين والمشتريات والمصاريف والصندوق والفواتير والإيصالات والتقارير
وتصدير Excel والمستخدمين والصلاحيات ومركز الإدارة.

**ملف واحد يعمل مباشرة.** افتح `index.html` بالنقر المزدوج — لا تثبيت، لا خادم، لا إنترنت. كل البيانات تُحفظ
محلياً في متصفحك (localStorage).

---

## 🚀 التشغيل

| الطريقة | الأمر |
|---|---|
| **الأسهل** | افتح `index.html` بالنقر المزدوج في أي متصفح حديث |
| خادم محلي (اختياري، يفعّل PWA + خط Tajawal من الإنترنت) | `npm run serve` ثم افتح `http://localhost:4173` |
| البناء من المصادر | `npm run build` → يولّد `index.html` |
| الاختبارات | `npm test` (يبني ثم يشغّل 177 فحصاً وظيفياً على jsdom) |

**تسجيل الدخول الافتراضي:** المستخدم `admin` — كلمة المرور `1234` (يطلب النظام تغييرها عند أول دخول).
من «الإدارة ← المستخدمون» أضف بقية الموظفين: مبيعات، محاسب، مخزن، أو دور مخصص بصلاحيات تفصيلية.

> **النظام يبدأ فاضياً** (بدون بيانات تجريبية) كما طلبت. للتجربة: «الإدارة ← نسخ احتياطي ← 🧪 تحميل بيانات تجريبية»،
> وللتفريغ: «🧹 تفريغ البيانات» أو «♻️ إعادة ضبط النظام».

## 📦 محتوى النظام

**الإدارة:** لوحة تحكم (8 مؤشرات + رسوم + تنبيهات + مهام اليوم + تقويم مالي)، تنبيهات، مهام اليوم، تقويم مالي.

**المبيعات:** نقطة بيع POS (بحث/باركود، بطاقة منتج، سلة، خصم، نقدي أو تقسيط)، جميع المبيعات، فواتير،
عروض أسعار، حجوزات، مرتجعات.

**العملاء:** زبائن (ملف كامل: معلومات، مشتريات، أقساط، تسديدات، فواتير، ضمان، صيانة، توصيل، كشف حساب)،
أقساط (كل الأقساط / مستحقة اليوم / متأخرة / حسب الزبون)، تسديدات مع توزيع تلقائي على الأقساط، كشوف حساب، أفضل الزبائن.

**المخزون:** منتجات (مع تاريخ تغيّر الأسعار)، أقسام، مخزون (جرد وتسويات)، طباعة باركود، تغيّر الأسعار،
أصناف راكدة، حركة منتج (كاردكس).

**المشتريات:** فواتير شراء (تحدّث الكلفة بالمتوسط المرجّح وتضيف للمخزون)، موردون، حسابات موردين ومدفوعات.

**الخدمات:** ضمان (🟢 داخل الضمان / 🟠 قريب الانتهاء / 🔴 منتهي — مع رقم السيريال)، صيانة
(استلام ← فحص ← إصلاح ← جاهز ← تسليم، مع الفني والكلفة)، توصيل (السائق والأجرة والحالة)، استبدال.

**المالية:** صندوق (رصيد متوقّع = افتتاح + نقد + بطاقات + تسديدات + دفعات موردين − مصاريف − مرتجعات)،
مصاريف بفئات، أرباح (هامش افتراضي 25% قابل للتغيير)، إغلاق اليوم (قفل اليوم وتعديل المدير فقط + كشف يوم كامل).

**التقارير:** مبيعات، أرباح، زبائن، أقساط، تسديدات، مخزون، منتجات، مشتريات، موردون، مصاريف، ضمان، صيانة، توصيل —
كلها بحث + فلترة + ملخّص + طباعة + PDF + Excel.

**مركز Excel:** تصدير بفترتين (من تاريخ → إلى تاريخ) لـ: زبائن، مبيعات، أقساط، تسديدات، منتجات، مخزون،
مشتريات، موردون، مصاريف، أرباح — بتصدير جماعي أو مفرد، مع ورقة ملخّص. ملفات `.xlsx` أصلية
(مبنية داخلياً بدون مكتبات خارجية).

**الإدارة العامة:** بيانات المحل، تخصيص النظام (اللون الرئيسي، الوضع الليلي، شكل القائمة، شكل الفاتورة، الشعار،
حجم الخط، اللغة، العملة)، إعدادات البيع، إعدادات الأقساط (أقصى عدد أشهر، حد الدفعة الأولى، التقريب، رسوم التأخير)،
إعدادات الفاتورة (A4/A5/80mm/58mm)، إعدادات الطباعة، الأمان (مستخدمون/صلاحيات/كلمات مرور/جلسات/سجل نشاط/
عمليات حساسة/نسخ احتياطي واستعادة)، استيراد Excel للمنتجات والزبائن، تحليلات ذكية (الأكثر مبيعاً، راكد،
أفضل الزبائن، أفضل الأيام، اتجاه المبيعات، ارتفاع الأسعار، أقساط متأخرة، قائمة إعادة الطلب، مصاريف مرتفعة).

**متعدد الفروع (جاهز):** كل سجل يحمل `branchId`، ويمكن إضافة الفروع من مركز الإدارة.

**PWA:** `manifest.webmanifest` + `sw.js` — عند تقديمها عبر خادم تظهر كأيقونة مستقلة وتعمل بدون إنترنت.

## 🎨 التصميم

لوحة الألوان: خلفية `#F5F7FA`، أساسي `#172033`، ثانوي `#2563EB`، نجاح `#16A34A`، تحذير `#F59E0B`، خطر `#DC2626`،
بطاقات بيضاء، حدود فاتحة، ظلال ناعمة. خط **Tajawal** (يُحمّل من Google Fonts عند توفر إنترنت، ويسقط تلقائياً
إلى خطوط النظام بدونه). أرقام بفواصل `1,250,000`.

متجاوب بالكامل: **شريط سفلي على الجوال** (الرئيسية | بيع | زبائن | تسديد | ☰) و**قائمة جانبية ثابتة على المكتبي**.
وضع ليلي كامل محفوظ في التفضيلات، ومؤثرات هادئة (انتقال صفحات، ظهور بطاقات، Skeleton، Toasts، نوافذ،
قوائم منسدلة، أشرطة تقدّم، عدّ أرقام).

    13-admin.js       مركز الإدارة الكامل + الاستيراد
    14-seed.js        بيانات تجريبية اختيارية

## ⚠️ ملاحظات مهمة

1. **البيانات محفوظة في المتصفح** (localStorage). لا تنتقل بين جهازين — استخدم **نسخة احتياطية** يومياً
   («الإدارة ← نسخ احتياطي»), واحتفظ بالملف في مكان آمن. «استعادة» تستبدل البيانات الحالية بالكامل.
2. **الطباعة إلى PDF** تتم عبر نافذة الطباعة (اختر "حفظ كـ PDF"). الطباعة مُهيّأة لمقاسات A4/A5/80mm/58mm.
3. **كود QR للفواتير** هو الاستثناء الوحيد الذي يتصل بالإنترنت: يُطلب من `api.qrserver.com`، وإذا تعذّر الوصول
   يختفي الرمز بهدوء دون أن يؤثر على الفاتورة. كل شيء آخر يعمل بلا اتصال.
4. **السعر والربح يُثبَّتان داخل الفاتورة لحظة البيع**، فتغيير أسعار المنتجات لاحقاً لا يغيّر الفواتير القديمة.
5. **إغلاق اليوم** يمنع أي تعديل أو حذف لحركات الأيام المغلقة (عدا المدير).
6. **دفعات الأقساط** تُوزَّع تلقائياً على الأقساط من الأقدم، مع دعم الدفع الجزئي وإعادة الاحتساب،
   والدفع الزائد يتحوّل إلى رصيد دائن للزبون.

## ✅ الاختبارات

`npm test` يبني الملف ثم يشغّله داخل jsdom ويفحص 177 assertion على مسارات حقيقية: الإقلاع وتسجيل الدخول، رسم لوحة التحكم
(8 مؤشرات)، البيع النقدي (خصم المخزون، حركة المخزون، الضمان، المقبوض، ربح الفاتورة)، رفض البيع فوق المتاح،
محرك الأقساط (التوزيع، التقريب، تواريخ الاستحقاق، الحالة)، بيع بالتقسيط مع دفعة أولى ورفض دفعة أقل من الحد،
توزيع تسديد 150,000 على قسطين، إعادة الاحتساب عند إلغاء تسديد، المتأخرات، الصندوق وإغلاق اليوم،
المشتريات والمتوسط المرجّح للكلفة ورصيد المورد، التقارير، توليد ملف Excel صالح (يُتحقق من ZIP ومحتواه)،
المستندات العشرة، **رسم كل الشاشات دون استثناء**، نقطة البيع بنوافذها، الصلاحيات، التنبيهات، التحليلات،
النسخ الاحتياطي والاستعادة (مع بقاء جلسة المستخدم)، سجل النشاط، والتخزين المحلي،
ومسار نقرات حقيقي بالكامل: قائمة الزبائن ← ملف الزبون ← التنقل بين التبويبات ← نافذة التسديد ← حفظ ← طباعة الوصل،
والتراجع عن تسديد عبر زر الواجهة نفسه، والبحث الموحّد (اسم/هاتف/منتج/باركود/رقم فاتورة).
